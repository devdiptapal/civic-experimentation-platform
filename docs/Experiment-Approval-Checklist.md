# Experiment Approval Checklist

Complete this checklist before launching any pilot.

## A. Purpose and Scope

- [ ] Pilot objective is clearly documented.
- [ ] Scope is narrow, specific, and reversible.
- [ ] Expected participant and staff impact is described.
- [ ] Out-of-scope uses are explicitly listed.

## B. Ethics and Equity

- [ ] Potential unequal impacts have been reviewed.
- [ ] Accessibility implications have been assessed.
- [ ] No group is excluded without documented reason.
- [ ] Participant burden has been considered and minimized.
- [ ] Support path exists for participants who experience issues.

## C. Privacy and Data Protection

- [ ] Data elements are minimized to required fields.
- [ ] No PII is used by default, or use is justified and approved.
- [ ] Access controls are defined and role-based.
- [ ] Retention and deletion schedule is documented.
- [ ] Aggregation thresholds are set for reporting.
- [ ] Re-identification risk has been reviewed.

## D. Measurement and Evaluation

- [ ] Hypothesis is documented in plain language.
- [ ] Primary metric is defined.
- [ ] Guardrail metrics and thresholds are defined.
- [ ] High-level sample size approach is documented.
- [ ] High-level analysis plan is documented.
- [ ] Decision rule (promote/iterate/rollback) is predefined.

## E. Operational Readiness

- [ ] Implementation owner is assigned.
- [ ] Monitoring owner is assigned.
- [ ] Incident response and escalation contacts are documented.
- [ ] Rollback trigger and process are documented.
- [ ] Internal communications plan is ready.

## F. Governance and Auditability

- [ ] Required reviewers have provided approval.
- [ ] Decision rationale is logged.
- [ ] Versioned pilot artifacts are archived.
- [ ] Post-pilot readout owner and timeline are defined.
