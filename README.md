# Civic Experimentation Platform

An open-source, documentation-first scaffold for testing and improving digital public services.

This project is intended to help public agencies and civic partners run careful, low-risk experiments on service delivery workflows such as benefits enrollment forms, eligibility steps, and service communications.

## Status

**Status: early-stage (v0.1)**

This repository is an initial public scaffold. It is designed for learning and adaptation, not as a production-ready system.

## Who This Is For

- State and county agencies responsible for benefits and service delivery
- Civic nonprofits and public-interest technology teams
- Researchers and evaluators supporting service improvement
- Program operations teams that need practical, plain-English guidance

## What This Enables

- Structured A/B test planning for service content and process changes
- Reusable evaluation templates for agency pilots
- Consistent experiment approval, privacy, and governance checks
- Better documentation for auditability and cross-jurisdiction learning

## What Is Included

- Governance, contribution, privacy, and security documentation
- A pilot deployment guide for agencies
- A reusable evaluation template
- An experiment approval checklist
- A sample, placeholder experiment configuration
- A plain-language glossary

## What Is Not Included

- Production application code
- Live integrations with agency systems
- Real user data or data pipelines
- Legal advice, policy determinations, or compliance guarantees

## How to Get Involved

1. Read `CONTRIBUTING.md` for contribution workflow and expectations.
2. Open an issue to suggest a documentation improvement, a template change, or a pilot use case.
3. Submit a pull request with clear context, plain-English edits, and references to any affected docs.
4. Start small: docs-first contributions are welcome and encouraged.

## Project Values

- Public benefit and service reliability
- Privacy by design and data minimization
- Transparency, auditability, and accountability
- Reuse across jurisdictions without vendor lock-in
